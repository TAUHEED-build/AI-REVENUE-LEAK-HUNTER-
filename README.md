# 🔍 AI Revenue Leak Hunter

> **Find where your business is losing money — before the leak gets bigger.**

An enterprise-grade B2B business intelligence system that analyzes uploaded financial data (CSVs/Excel) to detect uncollected payments, dormant high-value leads, customer churn risks, and duplicate invoices in seconds.

---

## ⚡ Key Features

- **Deterministic Rule Engine:** Calculates exact numbers and financial metrics without LLM math hallucinations.
- **Severity Classification:** Automatically categorizes findings into **CRITICAL**, **HIGH**, **MEDIUM**, and **LOW** risk buckets.
- **Evidence-Based Panel:** Inspect actual affected rows and records driving each revenue leak.
- **Human-in-the-Loop Workflow:** Actionable recommendations requiring explicit human approval before execution.

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Icons:** Lucide React
- **AI Integration:** Google Gemini API (Structured Output)
- **Deployment:** Vercel / Netlify
